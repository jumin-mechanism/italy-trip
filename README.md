# 주민·윤진 이탈리아 — 여행 일정 + 지도 웹앱

날짜별 시간표와 지도를 한 화면에서 보고, 지도 위에 경로·영역·메모 핀을 직접 그리는 웹앱입니다.
빌드 과정 없이 폴더째 정적 호스팅에 올리면 됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면, 스타일, 스크립트) |
| `data.json` | 처음 데이터: 10일 일정 56건, 장소 64곳, 구글어스 루트 10개 |
| `sw.js` | 서비스 워커. 앱 파일·지도 타일·글꼴을 저장해 오프라인에서도 열림 |
| `manifest.webmanifest`, `icons/` | 폰 홈 화면에 앱처럼 설치하기 위한 파일 |
| `vendor/` | Leaflet 1.9.4, Leaflet-Geoman 2.17.0 (둘 다 MIT 라이선스) |

## 올리는 방법

서비스 워커와 위치 기능은 **https**에서만 동작합니다. `file://`로 열면 일정·지도는 보이지만 오프라인 저장과 내 위치가 안 됩니다.

### A. GitHub Pages (가장 간단)
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. Settings → Pages → Branch를 `main` / `(root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`로 열립니다.

> 공개 저장소의 Pages는 주소를 아는 누구나 볼 수 있어요. `data.json`에 숙소 이름과 일정이 들어 있으니,
> 신경 쓰이면 B 방법을 쓰거나 `data.json`에서 숙소를 지우고 앱에서 직접 추가하세요.

### B. 직접 운영하는 서버 (GeoLocus 서버 등)
- nginx/Apache 아무 경로에나 폴더를 올리면 됩니다. 하위 경로(`/trip/`)도 문제없습니다.
- `.webmanifest`가 `application/manifest+json`으로 나가는지만 확인하세요.
- `sw.js`, `index.html`, `data.json`은 캐시를 짧게 두면 수정이 바로 반영됩니다.
- 비공개로 쓰려면 Basic Auth를 걸면 됩니다.

### 로컬에서 미리 보기
```bash
python -m http.server 8000   # http://localhost:8000
```

## 폰에 설치
- **아이폰**: Safari로 열기 → 공유 → "홈 화면에 추가"
- **안드로이드**: Chrome으로 열기 → 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

## 사용법
- **날짜 칩**: 날짜를 고르면 그날 일정과 지도가 바뀝니다. 여행 중에는 이탈리아 날짜 기준으로 오늘이 자동 선택됩니다.
- **일정**: 항목을 누르면 시간·상태(확정/계획/완료)·장소·메모를 고칠 수 있습니다. 장소가 연결된 일정은 지도에 번호 핀으로 표시되고, 시간 순서대로 점선이 이어집니다.
- **지도에 그리기**: 지도 왼쪽 도구(메모 핀 / 선 / 영역 / 편집 / 지우개)로 그리면 지금 선택한 날짜에 저장됩니다.
- **장소 추가**: 지도를 길게 누르거나(폰) 오른쪽 클릭(PC)합니다. 장소 팝업에서 구글맵 열기, 길찾기, 이 날 일정에 추가를 할 수 있습니다.

## 둘이 같이 쓰기
수정 내용은 각 기기 브라우저에 저장됩니다. 서버나 계정은 없습니다.
1. 메뉴 → **여행 파일 보내기**: 폰에서는 카톡 등으로 바로 공유되고, PC에서는 .json으로 저장됩니다.
2. 받은 쪽에서 메뉴 → **받은 여행 파일 합치기**를 누릅니다. 같은 항목은 더 최근에 고친 쪽이 남고, 지운 항목도 반영됩니다.

## 오프라인
- 한 번 열어 둔 화면의 지도 타일은 자동으로 저장됩니다(최대 약 5,000장).
- 출발 전에 각 도시를 적당히 확대해 놓고 메뉴 → **지금 보이는 지도 저장**을 누르면, 현재 화면부터 두 단계 더 확대한 범위까지 저장됩니다. 한 번에 450장까지 가능하니 동네 단위로 나눠 저장하세요.
- 지도 타일은 OpenStreetMap의 무료 공개 타일을 씁니다(API 키 불필요). 개인 여행 용도로는 괜찮지만 대량 다운로드는 이용 정책에 어긋나니 필요한 동네만 저장하세요. 길찾기는 구글맵 오프라인 지도도 함께 받아 두는 걸 추천합니다.

## 구글어스 · 마이맵스
- **KML로 내보내기**: 날짜별 폴더와 장소 전체 폴더로 정리된 KML이 만들어집니다.
- **KML 가져오기**: 점은 장소로, 선과 다각형은 지금 날짜의 그린 경로로 들어옵니다.

## 데이터 다시 넣기
`data.json`을 고쳐 서버에 다시 올린 뒤 메뉴 → **처음 데이터로 되돌리기**를 누르면 그 데이터로 새로 시작합니다.
이 기기에서 고친 내용은 사라지니, 먼저 여행 파일로 내보내 두세요.

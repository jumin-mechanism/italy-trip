# 주민·윤진 이탈리아 — 여행 일정 + 지도 웹앱

날짜별 시간표와 지도를 한 화면에서 보고, 지도 위에 경로·영역·메모 핀을 직접 그리는 웹앱입니다.
빌드 과정 없이 폴더째 정적 호스팅에 올리면 됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면, 스타일, 스크립트) |
| `data.json` | 처음 데이터 (버전 2): 10일 일정 56건, 장소 80곳, 구글어스 루트 10개 |
| `sw.js` | 서비스 워커. 앱 파일과 한 번 본 지도를 저장해 오프라인에서도 열림 |
| `manifest.webmanifest`, `icons/` | 폰 홈 화면에 앱처럼 설치하기 위한 파일 |
| `vendor/` | Leaflet 1.9.4, Leaflet-Geoman 2.17.0 (둘 다 MIT 라이선스) |
| `server-sync/` | (선택) 자동 동기화용 서버 코드. GitHub Pages에는 올리지 않아도 됨 |

## 올리는 방법

서비스 워커와 위치 기능은 **https**에서만 동작합니다.

### GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. Settings → Pages → Branch를 `main` / `(root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`로 열립니다.

> 공개 저장소는 누구나 `data.json`(숙소 이름, 일정)을 볼 수 있어요.

### 직접 운영하는 서버
아무 경로에나 폴더를 올리면 됩니다. Express라면 `app.use('/trip', express.static('trip-app'))` 한 줄입니다.

## 새 버전으로 바꿀 때
- 바뀐 파일을 같은 이름으로 다시 올리면 됩니다. 앱을 열어 둔 상태면 "새 버전이 준비됐어요" 알림이 뜹니다.
- `data.json`의 `version`이 올라가면, 앱이 **이 기기에서 손대지 않은 항목만** 새 내용으로 바꾸고 새 항목을 더합니다. 직접 고치거나 지운 것은 그대로 둡니다.

## 폰에 설치
- **아이폰**: Safari로 열기 → 공유 → "홈 화면에 추가"
- **안드로이드**: Chrome으로 열기 → 메뉴 → "앱 설치"

설치한 뒤에는 홈 화면 아이콘으로만 여세요. 아이폰은 브라우저와 앱이 데이터를 따로 저장합니다.

## 사용법
- **날짜 칩**: 날짜를 고르면 그날 일정과 지도가 바뀝니다.
- **일정**: 항목을 누르면 시간·상태·장소·메모를 고칩니다. 장소가 연결된 일정은 지도에 번호 핀으로 나옵니다.
- **지도에 그리기**: 지도 왼쪽 도구로 선·영역·메모 핀을 그리면 선택한 날짜에 저장됩니다.
- **장소 추가**: 장소 탭의 "이름으로 장소 찾아 추가"(인터넷 필요)나, 지도를 길게 누르기(PC는 오른쪽 클릭).
- **되돌리기**: 일정·장소·경로를 지우면 몇 초 동안 "되돌리기" 버튼이 나옵니다.
- **이름 미확인 장소**: 팝업의 "구글맵"으로 이름을 확인한 뒤 "수정"으로 바꾸면 됩니다.

## 둘이 같이 쓰기
수정 내용은 각 기기에 저장됩니다. 맞추는 방법은 두 가지입니다.

### 파일로 주고받기 (준비 없이 바로)
메뉴 → **여행 파일 보내기**로 보내고, 받은 쪽에서 **받은 여행 파일 합치기**. 같은 항목은 더 최근에 고친 쪽이 남습니다.
동기화를 안 쓰는 동안에는 10번 넘게 고치면 일정 위에 백업 안내가 나옵니다.

### 자동 동기화 (선택, 서버 필요)
`server-sync/trip-sync.js`는 Express 라우터 하나짜리 저장소입니다. 데이터베이스 없이 JSON 파일 하나로 보관합니다.

```js
// server.js — helmet, 로그인 검사, CSRF 미들웨어보다 위에
app.use('/api/trip-sync', require('./trip-sync')({
  code: process.env.TRIP_SYNC_CODE,            // 16자 이상 임의 문자열
  origins: ['https://<아이디>.github.io'],      // 앱이 열리는 주소 (끝에 / 없이)
}));
```

그다음 두 폰의 메뉴 → **자동 동기화**에 같은 값을 넣습니다.
- 서버 주소: `https://<서버>/api/trip-sync/<공간이름>` (공간이름은 영문 소문자·숫자·`-`)
- 코드: 위 `TRIP_SYNC_CODE`

앱을 열 때, 고친 직후, 그리고 20초마다 서로 맞춥니다. 인터넷이 없으면 기기에만 저장했다가 연결되면 맞춥니다.
코드는 폰 브라우저 저장소에 그대로 보관되니, 다른 곳에 쓰는 비밀번호를 넣지 마세요.

## 오프라인
- 앱과 일정은 한 번 열면 저장되어 인터넷 없이도 열리고, 고칠 수 있습니다.
- 지도는 **직접 본 곳만** 저장됩니다. 메뉴 → "오프라인 저장 상태"에서 몇 장 저장됐는지 볼 수 있습니다.
- 지도를 미리 한꺼번에 내려받는 기능은 없습니다. 지도 제공처(OpenStreetMap) 이용 정책이 금지하기 때문입니다.
- 인터넷 없이 쓸 지도는 Organic Maps나 구글맵 오프라인 지도를 함께 받아 두세요. 메뉴 → "KML로 내보내기" 파일을 Organic Maps에서 열면 핀과 경로가 들어갑니다.

## 구글어스 · 마이맵스
- **KML로 내보내기**: 날짜별 폴더와 장소 전체 폴더로 정리된 KML이 만들어집니다.
- **KML 가져오기**: 점은 장소로, 선과 다각형은 지금 날짜의 그린 경로로 들어옵니다.
